プライバシーポリシー

このポリシーは、{{OPERATOR}}（以下「運営者」）が運営する私的なアプリケーション「{{APP_NAME}}」（以下「本アプリ」）が Google アカウントのデータをどう扱うかを定めるものです。

利用者

本アプリを使うのは{{USERS}}だけです。それ以外の Google アカウントを接続することはありません。

取得するデータ

  • Google アカウントのメールアドレスと基本的なプロフィール（どのアカウントかを示すため）
  • Gmail のメール、ラベル、下書き、フィルタ
  • Google カレンダーのカレンダー一覧、予定、空き時間

利用の目的

運営者が自分の DeepSeek Harness で動かすボットに、利用者のメールと予定を扱わせるためだけに使います。広告、販売、機械学習モデルの学習などには使いません。

保存と管理

  • Google へのアクセスに使うトークンは、運営者が管理するコンピューターの中にだけ保存します。
  • メールや予定の内容は、ボットが処理するために、そのコンピューターの中で一時的に扱われます。新着メールや予定の変更の通知は、一定期間そのコンピューターに保存されます。
  • ボットの応答を作るため、メールや予定の内容の一部が、運営者が利用している言語モデルの提供元に送られることがあります。

第三者への提供

上記の言語モデルの提供元を除き、取得したデータを第三者に提供・販売することはありません。

Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

アクセスの取り消しと削除

本アプリのアクセスは、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。本アプリの設定画面でアカウントを切断すると、保存しているトークンも削除されます。
